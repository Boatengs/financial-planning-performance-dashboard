# Source & Modeling Policy

1. Portfolio project data must come from official, first-party, regulatory, government, or directly published institutional sources. Kaggle is not an approved source.
2. Raw source files are immutable. Transformations write only to `processed/`.
3. Every reported financial fact retains source, taxonomy tag, form, accession number and filing date where available.
4. Every derived KPI has a documented formula.
5. Budget, Forecast, Upside and Downside are analyst-created scenario layers and must be labeled as such in the UI, documentation and portfolio narrative.
6. No unavailable metric is backfilled by guesswork.
7. No missing geographic coordinate is invented.
8. Current route scope is reporting carrier `DL`; scope expansion to affiliates must be explicit and source-backed.
